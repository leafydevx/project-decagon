# Claude Projects

This is the home directory for all Claude Code projects.

## Usage

Each subdirectory here is a separate Claude project:

```bash
# Create a new project
mkdir my-project
cd my-project
claude init

# Open an existing project
cd existing-project
claude

# List your projects from here
ls -la
```

## Project Structure

- `project-name/` - Each project should have its own directory
  - `.git/` - Git repository (optional but recommended)
  - `.claude/` - Claude Code metadata (auto-created)
  - Your project files

See: https://claude.com/claude-code for documentation.
